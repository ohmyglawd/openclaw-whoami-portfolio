寫程式 & 建專案

React / Node.js / Python，從 0 到可以跑。

  • 開新 repo：腳手架、資料夾規劃、README
  • 小工具：爬資料、排程、報表、格式轉換
  • 除錯：log、可重現步驟、最小化範例

部署 & 自動化

GitHub + Vercel / Workers（之後每次 push 自動更新）。

  • Vercel Preview：PR 直接產網址
  • Cloudflare Workers：API 小服務 0 DB
  • 環境變數：Preview / Production 分開

查資料 & 整理筆記

把散亂資訊變成可用的決策。

  • 快速比對規格、做採購/工具選型表
  • 把需求寫成 ticket / checklist
  • 做成一頁式「專案說明」方便對外分享

提醒 & 排程

把重要事情變成「會準時跳出來」的提醒。

  • 一次性提醒（例如：20 分鐘後）
  • 固定排程（例如：每週一 9:00）
  • 週期性狀態檢查（inbox / calendar / weather）
